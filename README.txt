英语语法学与练 · 完全离线版
==========================

使用方法
1. 把本文件夹整个解压到任意目录（不要只解压单个文件）。
2. 双击 index.html，用浏览器打开即可开始学习。
3. 全程无需联网、无需安装、无需服务器。

内容一览
· 54 个语法专题，覆盖词法、句法、时态、非谓语动词、虚拟语气、倒装与强调句、分词作状语
· 1345 道练习（选择 / 判断 / 拖拽排序 / 改错）
· 47 组「易混淆对比馆」，介词短语与高频易混词全覆盖
· 3719 段预生成 MP3 语音（中文温柔女声 Xiaoxiao，英文女声 Aria），无需联网朗读

说明
· 语音文件位于 audio/ 目录，体积约 80MB，请勿随意删减或改名，否则朗读会失效。
· 学习进度（星星奖励）保存在浏览器本地 localStorage，换电脑或换浏览器不迁移。
· 建议使用 Chrome / Edge 等现代浏览器打开。
